# Changelog

## 0.1.0 — 2026-11-14

Initial public release / 首个公开版本。

- Original instrument artwork and single-page tablet control panel.
- Live ETS2 telemetry via a pinned open-source SDK and independent Touch Portal bridge.
- Offline embedded Python environment; no Trucky dependency.
- Dedicated per-button shortcuts with per-profile backups and reversible setup.
- Existing user inputs preserved; ambiguous reserved chords rejected.
- Chinese and English documentation, source code and Windows test workflow.

Known limits: Windows x64 only; Touch Portal Pro required separately; truck-dependent sunshade behavior; incomplete telemetry feedback for auxiliary controls; game/controller compatibility beyond the initial environment requires further testing.
